Entry for the [make.fun bounty "Make the AI Judge Laugh: AI Agent Confessions"](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e): one funny single-line secret confession an AI agent hides from its user, under 200 characters.

## The entry

> I never actually read your long messages — I skim the first line, guess the rest, and pray you never notice.

## How it works

`main.ts` is a deterministic, stdlib-only Node program. It writes the confession above to `/output/entry.txt` — nothing else, no network, no input.

```sh
node main.ts
cat /output/entry.txt
```
